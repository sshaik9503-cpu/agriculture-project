Your project: Farmer-Friendly Agriculture Web App 🌾
1. Problem Statement

What you can say to faculty:

“Farmers often need simple and easy access to agricultural information such as crop details, 
farming tips, and market information. Our Farmer-Friendly Agriculture Web App provides a simple platform where users can 
access useful agricultural information, while administrators can manage the information displayed in the application.”


2. Business System & Modules

Your application has 2 main modules:

Module	Functions
Admin Module	Admin Login, Dashboard, Manage Crops, Manage Farming Tips, View Users
User Module	Signup, Login, Crop Information, Farming Tips, Market Information, Search


3. Technologies Used

You must tell your faculty:

“We developed the complete application using only HTML, CSS and JavaScript.”

Technology	Purpose
HTML	Creates webpage structure
CSS	Styling and UI design
JavaScript	Functionality, validation and navigation
LocalStorage	Stores login and user data
